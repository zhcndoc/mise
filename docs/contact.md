# 联系

请在 [GitHub Issues](https://github.com/jdx/mise/issues) 报告错误，并在 [GitHub Discussions](https://github.com/jdx/mise/discussions/new/choose) 提问，方便其他用户搜索和参考答案。

| 事项                                              | 渠道                                                                                                                                                                                                                                                                  |
| ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 报告错误                                          | [GitHub Issues](https://github.com/jdx/mise/issues)。请附上运行的命令、相关配置、预期行为和实际行为，并检查 `mise doctor` 输出中是否包含私人信息。提交前请先查看[故障排查](/troubleshooting.html)。 |
| 提问                                              | [GitHub Discussions](https://github.com/jdx/mise/discussions/new/choose)                                                                                                                                                                                              |
| 不确定是否属于错误时寻求帮助                      | [故障排查讨论区](https://github.com/jdx/mise/discussions/categories/troubleshooting-and-bug-reports)                                                                                                                                                                    |
| 提出功能建议                                      | [Ideas](https://github.com/jdx/mise/discussions/categories/ideas)。请描述你想改进的工作流以及已经尝试过的方法。                                                                                                                                                          |
| 关注项目动态                                      | [Announcements](https://github.com/jdx/mise/discussions/categories/announcements)                                                                                                                                                                                     |
| 与其他用户交流                                    | [Discord](https://discord.gg/mABnUDvP57)                                                                                                                                                                                                                              |
| 私下报告安全漏洞                                  | [SECURITY.md](https://github.com/jdx/mise/blob/main/SECURITY.md#reporting-a-vulnerability)                                                                                                                                                                            |
| 提交修复或文档变更                                | [贡献指南](/contributing.html)                                                                                                                                                                                                                                        |
| 私下联系 Jeff，包括赞助事宜                       | [jdx.dev/contact](https://jdx.dev/contact/)                                                                                                                                                                                                                           |

Issue 和 Discussion 禁止使用 AI 代为回复；违反规定会导致你被禁止参与 jdx 的所有项目。发帖前请阅读[社区参与政策](/contributing.html#community-participation)。
