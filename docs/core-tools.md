# 核心工具

`mise` 在 CLI 中内置了一些用 Rust 编写的插件。这些插件是新的，并且会随着时间推移不断改进。

你可以通过安装同名的 asdf/vfox 插件轻松覆盖它们，例如：`mise plugin install python https://github.com/asdf-community/asdf-python`。

你可以使用 `mise registry -b core` 查看核心插件。

- [Bun](/lang/bun)
- [Deno](/lang/deno)
- [Elixir](/lang/elixir)
- [Erlang](/lang/erlang)
- [Go](/lang/go)
- [Java](/lang/java)
- [NodeJS](/lang/node)
- [Python](/lang/python)
- [Ruby](/lang/ruby)
- [Rust](/lang/rust)
- [Swift](/lang/swift)
- [Zig](/lang/zig)
