# `mise deactivate`

- **用法：** `mise deactivate`
- **效果：** 只读
- **源代码：** [`src/cli/deactivate.rs`](https://github.com/jdx/mise/blob/main/src/cli/deactivate.rs)

这可用于在 shell 会话中临时禁用 mise。
