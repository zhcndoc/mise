# `mise bootstrap macos defaults apply`

- **用法：** `mise bootstrap macos defaults apply [-n --dry-run] [-y --yes]`

## Flags
- **`-n --dry-run`** — Show what would change without changing anything
- **`-y --yes`** — Skip the confirmation prompt
